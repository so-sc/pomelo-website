## Docker Setup

Running `pnpm dev` automatically handles setting up and starting all required Docker containers (MongoDB and Citron).

If you prefer to manually control or inspect the backing services, Pomelo includes Docker Compose definitions in `docker/app/` and `docker/citron/`.

### Manual Container Management

<CodeBlock filename="terminal" language="bash" code={`docker compose --project-name pomelo --env-file .env \\
  -f docker/app/docker-compose.dev.yaml \\
  -f docker/citron/docker-compose.dev.yaml \\
  --project-directory . up mongo citron -d`} />

### Services

<div class="space-y-2">
  <ServiceCard name="mongo" description="MongoDB database for contest and user data." port="27017" />
  <ServiceCard name="server" description="Express API for auth, contests, and submissions." port="8080" />
  <ServiceCard name="client" description="Participant-facing web app." port="3000" />
  <ServiceCard name="citron" description="Sandboxed execution engine that compiles and runs submissions." port="2358" />
  <ServiceCard name="caddy" description="Reverse proxy and automatic SSL." port="80/443" />
</div>

Citron runs untrusted code, so it publishes no port in production and is reached only over the internal Compose network at `http://citron:2358`. In development it binds to `127.0.0.1:2358` for inspection.

### Stop containers

<CmdBar cmd="docker compose --project-name pomelo down" />

### Remove volumes

<CmdBar cmd="docker compose --project-name pomelo down -v" />
