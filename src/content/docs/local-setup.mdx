## Workspace Setup

Follow these steps to set up the Pomelo workspace on your local machine.

### Prerequisites

The Pomelo stack requires specific system tools to run locally and build. Make sure the following are installed:

- **[Node.js (`node`)](https://nodejs.org/)**: Required for the Next.js frontend and Express backend.
- **[Bun (`bun`)](https://bun.sh/)**: Used specifically to compile the CLI and Daemon binaries.
- **[pnpm](https://pnpm.io/)**: The strict package manager used across the monorepo workspace.
- **[Docker & Docker Compose](https://www.docker.com/)**: Required for the database and Judge0 execution environment.

### 1. Clone the repository

Clone the repository to your local machine:

<CmdBar cmd="git clone https://github.com/so-sc/pomelo && cd pomelo" />

### 2. Install workspace dependencies

Run `pnpm install` at the repository root to install all workspace dependencies.

<CmdBar cmd="pnpm install" />

### 3. Set up environment variables

Copy `.env.example` to `.env`:

<CmdBar cmd="cp .env.example .env" />

### 4. Start development mode

Run `pnpm dev` to start the development environment:

<CmdBar cmd="pnpm dev" />
