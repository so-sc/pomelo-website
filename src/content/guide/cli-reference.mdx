## CLI Command Reference

The full set of commands available through the `pomelo` CLI:

| Command | Description |
| :--- | :--- |
| `pomelo start` | Starts all Pomelo services (Docker containers, database, server, client, and the Citron engine). |
| `pomelo stop` | Stops all currently running Pomelo services. |
| `pomelo restart` | Stops then restarts all services. Use this to apply configuration changes. |
| `pomelo status` | Displays the health and running status of all Pomelo services. |
| `pomelo logs [source]` | Tails logs for a source. Defaults to `app` (all services). |
| `pomelo ui` | Opens the Admin UI dashboard in your default web browser (port 8462). |
| `pomelo uninstall` | Uninstalls Pomelo and removes its containers, volumes, and systemd service. |

### Viewing Logs

<CmdBar cmd="pomelo logs [source] [--follow] [--tail N]" />

`--tail` defaults to 200 lines. Valid sources:

| Source | What It Shows |
| :--- | :--- |
| `app` | All Compose services at once. This is the default. |
| `daemon` | The `pomelod` daemon's own log file. |
| `server` | Express API: auth, contests, submission handling. |
| `client` | Next.js frontend. |
| `citron` | Execution engine: compilation and run output. |
| `mongo` | MongoDB database. |
| `caddy` | Reverse proxy and SSL certificates. |

<CmdBar cmd="pomelo logs citron --follow" />

This is useful for debugging startup failures, network issues, or unexpected submission errors without opening the Admin UI.

### Uninstalling

<CmdBar cmd="pomelo uninstall" />

Each mode prompts for confirmation before doing anything:

| Flag | Behaviour |
| :--- | :--- |
| *(none)* | Removes configuration, preserves your contest data. |
| `--keep-data` | Preserves both data and configuration. |
| `--full` | Also deletes all data, the database, and configuration. |

### Opening the Admin UI

Instead of remembering the port number, use the built-in shortcut:

<CmdBar cmd="pomelo ui" />

This opens `http://localhost:8462` (or your configured Admin CLI port) in your default browser.
